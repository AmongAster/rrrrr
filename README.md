# ModForge theme for AzuriomCMS

Готовая тема `modforge` для AzuriomCMS под модовый Minecraft-проект с заготовленной интеграцией под плагины **SkinAPI**, **Shop** и **FAQ**.

## Что внутри

- sci-fi / launcher-first визуальный стиль для главной страницы;
- настраиваемые CTA, IP сервера, ссылки и тексты через конфиг темы;
- отдельные шаблоны-обертки для страниц плагинов `skin-api`, `shop` и `faq`;
- RU/EN локализация;
- кастомные CSS/JS-ассеты без jQuery.

## Структура

```text
themes/modforge/
├── assets/
├── config/
├── lang/
├── views/
├── config.json
└── theme.json
```

## Установка

1. Скопируйте папку `themes/modforge` в директорию `themes/` вашего Azuriom-проекта.
2. Активируйте тему в админ-панели Azuriom.
3. Откройте настройки темы и заполните ссылки, тексты и данные сервера.
4. Если ваши плагины используют другие Blade-шаблоны, перенесите стили/блоки из `views/plugins/*` в соответствующие view overrides плагинов.

## Интеграции

### SkinAPI

Тема добавляет отдельную страницу-обертку с блоком быстрых действий и секцией для контента плагина: `views/plugins/skin-api/index.blade.php`.

### Shop

Для магазина подготовлен шаблон с hero-блоком, карточкой рекомендуемого набора и секцией под стандартный вывод пакетов: `views/plugins/shop/packages.blade.php`.

### FAQ

FAQ оформлен в едином стиле и поддерживает выделенный поисковый блок и карточки частых вопросов: `views/plugins/faq/index.blade.php`.

## Основа реализации

Тема собрана по структуре и рекомендациям официальной документации Azuriom по разработке тем.
